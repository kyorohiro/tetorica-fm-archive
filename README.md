Tetorica FM Archive

An archive of FM synthesis research, analysis, patches, and musical experiments.

This repository is the long-term storage area for analyzed materials gathered while studying FM sound chips such as the YM2612, YM2203, and YM2608.

Contents

* FM sound analysis notes
* Instrument and patch data
* Music analysis snapshots
* Exported TFI and related patch files
* Playground examples and experiments
* Research memos

Recommended layout

* `analysis/` for song-by-song notes and findings
* `patches/` for TFI, preset, and extracted voice data
* `snapshots/` for analyzer exports and captured states
* `examples/` for small runnable code and demos
* `notes/` for rough work, references, and study memos
